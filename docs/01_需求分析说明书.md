# 需求分析说明书

## 1. 引言

### 1.1 编写目的

本文档描述「健身热量记录控制推荐系统」的功能需求与非功能需求，作为后续概要设计、详细设计、编码与测试的依据。预期读者为课程指导教师、开发团队及项目评审人员。

### 1.2 项目背景

随着健康意识的提升，减脂健身成为大学生与上班族的常见诉求。然而，多数人缺乏科学的饮食与运动管理手段，常陷入盲目节食或运动无效的困境。本系统通过自动化热量核算与个性化方案推荐，帮助用户科学管控减脂热量、提升减脂规划效率。

### 1.3 术语说明

| 术语 | 说明 |
|------|------|
| BMR | 基础代谢率（Basal Metabolic Rate），人体静息状态下的能量消耗 |
| TDEE | 每日总能量消耗（Total Daily Energy Expenditure） |
| MET | 代谢当量（Metabolic Equivalent），衡量运动强度的指标 |
| 热量缺口 | 每日摄入与消耗的负差值，是减脂的核心原理 |

## 2. 系统目标

面向减脂健身人群，提供三大核心能力：

1. **饮食热量记录**：记录每日饮食，自动换算摄入热量。
2. **运动消耗统计**：记录运动，自动计算消耗热量。
3. **个性化方案推荐**：基于基础代谢与热量缺口算法，生成每日摄入目标与营养素配比建议。

## 3. 用户角色

本系统为**单用户本地应用**，仅存在一种角色：

| 角色 | 说明 |
|------|------|
| 普通用户 | 维护个人档案、记录饮食与运动、查看推荐方案与统计数据 |

## 4. 功能需求

### 4.1 个人档案管理

- 用户可录入/修改：性别、年龄、身高、体重、目标体重、活动水平、减脂目标。
- 系统持久化保存，作为所有算法计算的输入。

### 4.2 饮食热量记录

- 展示内置食物库，支持按名称搜索。
- 用户选择食物并输入克数，系统按「每100g热量×克数/100」自动计算热量并入库。
- 展示当日饮食清单，支持删除记录。
- 汇总当日总摄入热量。

### 4.3 运动消耗统计

- 展示内置运动库，支持按名称搜索。
- 用户选择运动并输入时长（分钟），系统按「MET×体重×时长」自动计算消耗热量并入库。
- 展示当日运动清单，支持删除记录。
- 汇总当日总消耗热量。

### 4.4 个性化方案推荐

- 计算基础代谢 BMR（Mifflin-St Jeor 公式）。
- 计算每日总消耗 TDEE = BMR × 活动系数。
- 根据减脂目标确定热量缺口，计算每日建议摄入热量。
- 给出三大营养素（蛋白质/碳水/脂肪）每日克数建议与饮水量建议。

### 4.5 仪表盘

- 展示今日摄入、运动消耗、建议摄入目标、剩余可摄入。
- 以柱状图展示近 7 日摄入与消耗趋势。

## 5. 非功能需求

| 类别 | 需求 |
|------|------|
| 性能 | 单用户本地，所有操作应在 1 秒内响应 |
| 可用性 | 界面简洁直观，中文界面，无需培训即可上手 |
| 可维护性 | 模块化设计，算法与数据层解耦，便于扩展 |
| 可移植性 | 仅依赖 Python 标准库 + Flask，跨平台运行 |
| 数据安全 | 数据存于本地 SQLite，单用户场景无隐私泄露风险 |

## 6. 运行环境

- 操作系统：Windows / macOS / Linux
- Python 3.8+
- 依赖：Flask 2.3+
- 浏览器：Chrome / Edge / Firefox 等现代浏览器

## 7. 验收标准

1. 能正确录入个人档案并保存。
2. 添加食物/运动后能正确计算热量并展示。
3. 能正确计算 BMR、TDEE 与目标摄入，并与人工手算结果一致（误差 < 1 kcal）。
4. 仪表盘能正确展示今日汇总与近 7 日趋势。
