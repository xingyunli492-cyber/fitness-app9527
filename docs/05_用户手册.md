# 用户手册

## 1. 系统简介

「健身热量记录控制推荐系统」是一款面向减脂健身人群的本地应用，帮你：

- 记录每日饮食，自动核算摄入热量；
- 记录运动，自动统计消耗热量；
- 根据身体数据生成个性化饮食运动方案，科学减脂不盲目节食。

## 2. 安装与启动

### 2.1 环境准备

确认电脑已安装 **Python 3.8 或更高版本**。

- Windows：在命令行输入 `python --version` 查看；若无，请到 python.org 下载安装。

### 2.2 启动步骤

1. 打开命令行（Win+R 输入 `cmd`），进入项目目录：

   ```
   cd 项目路径\fitness-app
   ```

2. 安装依赖：

   ```
   pip install -r requirements.txt
   ```

3. 启动应用：

   ```
   python app.py
   ```

4. 看到类似 `Running on http://127.0.0.1:5000` 的提示后，打开浏览器访问：

   ```
   http://127.0.0.1:5000
   ```

> 首次启动会自动创建数据库并写入内置食物库、运动库。

## 3. 使用指南

### 3.1 填写个人档案

1. 点击顶部导航「个人档案」。
2. 填写性别、年龄、身高、体重、目标体重，选择活动水平与减脂目标。
3. 点击「保存并生成方案」。

### 3.2 查看推荐方案

点击「方案推荐」，查看系统根据你的数据生成的：

- 基础代谢 BMR、每日总消耗 TDEE
- 每日热量缺口与建议摄入热量
- 蛋白质/碳水/脂肪每日克数、饮水量建议

### 3.3 记录饮食

1. 点击「饮食记录」。
2. 在左侧搜索框输入食物名（如"米饭"），选择食物，输入克数，点击「添加」。
3. 右侧「今日饮食清单」会显示记录与自动计算的热量，顶部显示今日总摄入。

### 3.4 记录运动

1. 点击「运动记录」。
2. 选择运动，输入时长（分钟），点击「添加」。
3. 系统按你的体重与运动强度自动计算消耗热量。

### 3.5 查看仪表盘

点击「仪表盘」，查看今日摄入、消耗、建议目标、剩余可摄入，以及近 7 日趋势图。

## 4. 常见问题

**Q：找不到 Python 命令？**
A：安装 Python 时勾选「Add Python to PATH」，或使用完整路径运行。

**Q：端口被占用？**
A：编辑 `app.py` 中 `app.run(port=5000)` 的端口号，改为其他端口（如 8000）。

**Q：数据存在哪里？**
A：项目目录下的 `fitness.db` 文件，删除该文件可重置所有数据。

**Q：想增加食物/运动种类？**
A：编辑 `database.py` 中 `_seed_foods` / `_seed_exercises` 的种子数据，删除 `fitness.db` 后重启即可生效。

## 5. 减脂小贴士

- 减脂核心是「摄入 < 消耗」，即制造热量缺口，无需极端节食。
- 蛋白质要足量（约 1.6~2.0g/kg 体重），有助于保留肌肉。
- 每周 3~5 次运动，有氧 + 力量结合效果更佳。
- 保证睡眠与饮水，体重波动属正常现象，关注长期趋势。
