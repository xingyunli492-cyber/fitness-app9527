## 界面原型说明

界面原型采用移动端优先的响应式设计，包含五个页面：

- 仪表盘（`index.html`）— 今日热量概览 + 近 7 日趋势
- 饮食记录（`diet.html`）— 食物搜索 + 添加 + 清单
- 运动记录（`exercise.html`）— 运动搜索 + 添加 + 清单
- 方案推荐（`recommend.html`）— BMR/TDEE/营养素
- 个人档案（`profile.html`）— 身体数据录入

导航采用底部 Tab 栏（`base.html` 中定义），适配 360~430px 手机宽度。
