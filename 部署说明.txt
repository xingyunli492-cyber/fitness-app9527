============================================
  健身热量记录控制推荐系统 - 新电脑部署步骤
============================================

【第 1 步】把整个 fitness-app 文件夹拷贝到新电脑
   - U盘 / 移动硬盘 / 网盘 任意方式都可以

【第 2 步】在新电脑安装 Python（只装一次）
   1. 浏览器打开 https://www.python.org/downloads/
   2. 下载 Windows 安装包（Python 3.12.x）
   3. 双击安装，务必勾选底部 "Add python.exe to PATH"
   4. 一路 Next 装完
   验证：新开命令行输入  python --version  能显示版本号即可

【第 3 步】安装依赖（只装一次）
   双击 install.bat
   （会自动装 Flask，看到 "Done!" 即可）

【第 4 步】启动运行
   双击 start.bat
   浏览器会自动打开 http://127.0.0.1:5000

============================================
  说明
============================================
- start.bat 会优先找 D:\Python\python.exe，
  找不到就自动用系统 PATH 里的 python，两种都能跑。
- fitness.db 是数据库文件，首次运行自动生成，
  不需要手动创建；删掉它可以清空所有数据。
- 如果换电脑后 Python 装在别的位置（不是 D:\Python），
  不用改任何东西，只要装 Python 时勾选了"加入 PATH"即可。
