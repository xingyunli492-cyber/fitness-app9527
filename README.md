# 健身热量记录控制推荐系统

一款面向减脂健身人群的本地 Web 应用，提供**饮食热量记录**、**运动消耗统计**、**个性化饮食运动方案推荐**三大能力。基于基础代谢计算模型与热量缺口算法，自动核算每日摄入与消耗，科学管控减脂热量，避免盲目节食。

## 功能特性

- **饮食热量记录**：内置常见食物库（主食/肉蛋/蔬果/乳制品/零食饮品），按克数自动换算摄入热量。
- **运动消耗统计**：内置常见运动库（含 MET 代谢当量），按时长与体重自动计算消耗热量。
- **个性化方案推荐**：基于 Mifflin-St Jeor 公式计算基础代谢 BMR，乘以活动系数得 TDEE，再按减脂目标扣除热量缺口，生成每日摄入目标与三大营养素配比。
- **仪表盘可视化**：今日摄入/消耗/剩余可摄入概览 + 近 7 日趋势图。
- **个人档案管理**：性别、年龄、身高、体重、活动水平、减脂目标、目标体重。

## 技术栈

- 后端：Python + Flask
- 数据库：SQLite（标准库 `sqlite3`，零配置本地存储）
- 前端：原生 HTML + CSS + JavaScript（Jinja2 模板渲染）

## 本地部署运行

### 环境要求

- Python 3.8 及以上

### 步骤

```bash
# 1. 进入项目目录
cd fitness-app

# 2. （推荐）创建虚拟环境
python -m venv venv
# Windows 激活：
venv\Scripts\activate
# macOS / Linux 激活：
source venv/bin/activate

# 3. 安装依赖
pip install -r requirements.txt

# 4. 启动应用
python app.py
```

浏览器访问 **http://127.0.0.1:5000** 即可使用。

> 首次启动会自动创建 `fitness.db` 数据库文件，并写入内置食物库、运动库与默认用户档案。

## 算法说明

| 指标 | 公式/方法 |
|------|-----------|
| 基础代谢 BMR | Mifflin-St Jeor：男 `10×体重+6.25×身高-5×年龄+5`，女 `10×体重+6.25×身高-5×年龄-161` |
| 每日总消耗 TDEE | `BMR × 活动系数`（1.2~1.9） |
| 热量缺口 | 温和 300 / 标准 500 / 强化 700 kcal |
| 目标摄入 | `TDEE - 缺口`，下限保护 1200 kcal |
| 运动消耗 | `MET × 体重(kg) × 时长(小时)` |
| 食物热量 | `每100g热量 × 克数 / 100` |

## 使用示例

1. 打开「个人档案」，填写性别、年龄、身高、体重等信息，保存。
2. 查看「方案推荐」，获得每日摄入目标与营养素配比。
3. 在「饮食记录」搜索并添加当日饮食，系统自动计算热量。
4. 在「运动记录」添加运动，系统按 MET 计算消耗。
5. 返回「仪表盘」，查看今日热量平衡与近 7 日趋势。
