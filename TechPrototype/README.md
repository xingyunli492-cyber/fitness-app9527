## 技术原型说明

技术原型聚焦于**核心算法**的可实现性验证：

- `algorithms.py` — 纯函数算法模块，实现 BMR/TDEE/热量缺口/MET 消耗/营养素配比，与数据层解耦，可独立测试。
- 通过 pytest 单元测试验证算法正确性（见 `../tests/`）。
